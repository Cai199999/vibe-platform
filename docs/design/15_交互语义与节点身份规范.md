# 15 · 交互语义与节点身份规范

> 2026-11-18 · 冻结版。后续新增能力必须先对齐本规范，再改代码。

## 1. 总原则

1. **源码是唯一事实源**；OID / Source Map / instancePath 都是派生只读事实，不是第二棵可写树。
2. **只有一个写入口**：Direct Ops → AST Gate → ChangeLog → Git commit → sourceSync。
3. **乐观只发生在 UI 层**：允许先隐藏/位移，失败必须恢复；源码 commit 成功才算完成。
4. **不确定就 HITL，不支持就 fail-closed**；禁止用启发式猜一个“看起来像”的目标。

## 2. 身份模型

| 身份 | 产生方 | 作用 | 是否写入 DOM |
|---|---|---|---|
| `data-oid` | 构建期插件 / CodeGen | 稳定元素身份，写操作主键 | 是 |
| `callSiteOid` | 构建期插件 | 组件调用点身份，Props / 调用点操作 | 否，只在 Source Map |
| `instancePath` | 运行时 SDK | map/repeat 实例路径：父 oid 链 + 序号 | 否，随请求上报 |
| `instanceKey` | 运行时 SDK | instancePath 的字符串指纹 | 否 |
| `containerScope` | 构建期插件 | 父容器落点语义 | 否，只在 Source Map |
| `data-node-id` | Visual CodeGen | 逻辑节点 ID / 旧兼容 | 是 |
| `data-source` | 旧工程 / 调试 | `file:line[:column]`，仅兜底 | 是 |

### 解析优先级

```text
callSiteOid
  > data-oid
  > data-node-id / selector
  > data-source file:line[:column]
  > 祖先源码锚点
```

任何一级命中后都必须拿到 `file` + 精确 range/selector；拿不到就 `TARGET_NOT_FOUND`，禁止继续猜。

### 不变量

- 同一文件内 `data-oid` 唯一；
- oid 只由文件 + 组件 + JSX 结构签名决定，换行/空行不改变；
- `callSiteOid` 只标识“哪一处 JSX 使用了组件”，不注入组件 props；
- `instancePath` 只描述运行时实例，不改变源码身份；
- `containerScope` 必须由构建期确定，不能在运行时按标签猜。

## 3. 交互分级

| 级别 | 条件 | UI 行为 | 写入行为 |
|---|---|---|---|
| L0 本地安全 | `local` / 非 map / 非组件定义 / 单实例叶子 | 乐观立即生效 | 直接 AST 写 + commit |
| L1 调用点插槽 | `call_site_slot` 且唯一调用点 | 直接落位 | 写调用方 JSX |
| L2 范围不确定 | `component_definition` / `repeated_template` / 多实例 / 共享组件 | HITL 范围选择 | 用户确认后转 AI 或取消 |
| L3 不支持 | 跨文件、条件/循环调用点无法消歧、无源码锚点 | fail-closed | 不写 |

### 操作矩阵

| 操作 | L0 | L1 call_site_slot | L2 definition/template | L3 |
|---|---|---|---|---|
| 删除 | 立即删除 + 撤回 | 删除调用点 | HITL | 拒绝 |
| 文本 | 立即改 + commit | 改调用点文案 | HITL | 拒绝 |
| 新增 | 直接插入 | 插入调用点 children | HITL | 拒绝 |
| 移动 | 直接移动 | 移入调用点 children | HITL | 跨文件拒绝 |
| Props | 直接改调用点 | 直接改调用点 | HITL | 拒绝 |

## 4. 删除语义

- **安全叶子**：`deleteSafe=true` 且运行时单实例：
  - 点击即乐观隐藏；
  - 直接 execute DELETE_NODE；
  - 成功后左下角“撤回”可用；
  - 失败/HITL 自动恢复显示。
- **不安全节点**：先本地确认，再 execute；execute 返回 `HITL_REQUIRED` 时弹范围选择。
- **数据源删除**：`AI_DATA_EDIT` 目前只 `HANDOFF_TO_AI`，文案必须明确“已转交，未删除”；不得显示为删除成功。

## 5. 容器落点语义

| containerScope | 含义 | 写作用域 |
|---|---|---|
| `local` | 同文件同组件普通容器 | 当前 JSX |
| `call_site_slot` | 唯一调用点且组件转发 `{children}` | 调用方 JSX children |
| `component_definition` | 被其它文件引用的组件定义内部 | 定义，影响全部实例 |
| `repeated_template` | `.map()` / repeat 模板 | 模板，影响全部实例 |

## 6. 多调用点

- 调用点按源码顺序排序；
- 仅当所有调用点 `safeForOrder=true`、静态数量 == 运行时实例数时，用实例序号自动匹配；
- 条件渲染 / 循环调用点 → `callSiteAmbiguous=true`，HITL。

## 7. 持久化

- Direct Ops commit 成功后同步快照；
- 删除文件从快照移除；
- 失败任务进入本地补偿队列，指数退避重试；
- 快照 revision 只增不减，旧 revision 可审计。

## 8. 验收基线

- 安全叶子删除无 422、UI 立即响应、可撤回；
- 组件定义/重复模板修改必须出现 HITL；
- 旧工程 `file:line` 锚点仍可解析；
- 跨文件移动明确拒绝；
- 所有写操作经过同一 AST Gate 与 ChangeLog。
