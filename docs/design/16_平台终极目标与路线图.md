# 16 · 平台终极目标与路线图

> 2026-11-18 · 六个终极目标；当前阶段只做“类 Onlook 可视化闭环”，其余能力按里程碑推进。

## 终极目标

### G1 真实业务任务与量化
- 任务成功率、首次可用率、人工接受率、回滚率、单任务成本、P50/P95 延迟。
- 建立真实业务任务集与评分标准，不以单测数量代替业务价值。

### G2 完整后端工程体系
- 真实 JWT/OIDC + RBAC + 租户隔离。
- Run / 契约 / 审批 / 审计 / 指标落库，正式 migration。
- 结构化日志、统一异常、分布式锁、限流、幂等、审计查询。

### G3 任务规划与多 Agent
- 领域图式规划 + 通用任务拆解。
- 计划持久化、可解释、可恢复；工具失败重试与结果校验。
- 多 Agent 协作从固定编排走向可协商、成本感知。

### G4 上下文工程
- 分层记忆：用户画像、项目摘要、线程历史、RAG。
- 记忆写入策略、冲突消解、过期/衰减、召回评估。

### G5 评估与可观测
- 全链路 trace：BFF → AI Core → 模型 → 工具 → 沙盒。
- 成功率、耗时、token/成本按轮次持久化与可视化。
- 告警、回归对比、失败分类。

### G6 人机协同
- 高风险操作 HITL；模板/共享/跨文件不盲目自动化。
- 决策协议统一、可审计；支持人工接管与回滚。

## 当前阶段：类 Onlook 可视化闭环

范围：

1. 选中 → 删除/文本/新增/移动/Props。
2. 安全操作乐观执行，失败回滚。
3. OID / callSiteOid / instancePath / containerScope 全链路。
4. 拖拽落点容错与语义插入。
5. 撤回、ChangeLog、Git commit、sourceSync。
6. 不支持的操作 fail-closed，范围不确定走 HITL。
