# 11 · 离线优先可视化引擎（Offline-First Visual Engine）

> 2026-11-16 · 重大架构升级

## 1. 背景

旧链路把画布编辑直接映射到真实 React AST：

- 页面根节点不能真正删除，只能替换占位符；
- 架构师生成的父容器经常被识别为 route root / import 定义 / map 数据源；
- 新增组件受单文件 AST、import、JSX 合法性限制；
- 用户想自由调整布局时，系统只能保守拦截或走 LLM 修复。

根因不是 Direct Ops 实现不够好，而是**真实源码不适合承担高频视觉编辑**。

## 2. 核心决策

把系统拆成两个事实源阶段：

```text
生成前：VisualDocument（虚拟组件树）是唯一事实源
生成后：React 源码是唯一事实源
```

- 生成前不写源码、不启动沙盒、不 commit；
- 生成后 CodeGen 一次性编译，Direct Ops 降级为微调；
- 虚拟树只读层级与语义，不存像素 x/y；
- 第一版不做“源码修改反向同步回虚拟树”，避免双事实源冲突。

## 3. 状态流转

```text
INTENT
  ↓
ARCH_DRAFTING（Architect 输出 VisualDocument v0）
  ↓
CANVAS_EDITING（本地增删改拖 / 局部 Agent JSON Patch）
  ↓ 用户点击“生成全栈”
CANVAS_REVIEW（冻结 revision）
  ↓
BUSINESS_REVIEW（interactions / bindings 缺口多轮澄清）
  ↓ 必填 binding 全部确认
FROZEN（contentHash）
  ↓
CODEGEN（确定性编译器 + LLM 兜底）
  ↓
BUILD_VERIFY（AST / 构建 / 契约 / 数据库一致性）
  ↓
DEPLOYED
  ↓
MICRO_ADJUST（Direct Ops，基于 data-node-id 的源码微调）
```

任何阶段失败都回到最近稳定状态；`FROZEN` 后虚拟树不可直接编辑。

## 4. VisualDocument

顶层：

```json
{
  "schemaVersion": "1.0",
  "docId": "vdoc_...",
  "projectId": "proj_...",
  "revision": 0,
  "status": "DRAFT | REVIEW_READY | FROZEN | COMPILED",
  "designTokens": {},
  "root": {},
  "interactions": [],
  "bindings": [],
  "review": {},
  "metadata": {}
}
```

节点核心字段：

- `id`：稳定 `nd_...`，CodeGen 注入 `data-node-id`；
- `type`：page / section / container / grid / stack / text / button /
  input / image / list / table / form / modal / component；
- `props`：静态文案、占位符、图片地址等；
- `layout`：display / direction / gap / padding / align / justify /
  columns / minWidth / maxWidth，禁止 x / y；
- `style`：设计令牌、className、Tailwind；
- `children`：顺序即渲染顺序；
- `repeat`：列表 / 表格的数据源与示例数量；
- `semantics`：业务角色、目的、重要度、业务实体；
- `codegen`：primitive / composite / custom；
- `provenance`：创建者、revision、changeId。

校验规则：

- nodeId 唯一；
- 最大 5000 节点、20 层；
- 非容器不能有 children；
- 只有 list / table 支持 repeat；
- interaction / binding 必须指向有效节点；
- repeat.source 必须有 binding；
- 禁止像素坐标与原始 HTML 注入；
- root=null 是合法空白画布。

## 5. 阶段一实现

- Python：`ai_core/domain/visual_document.py`
- Python 测试：`tests/test_visual_document.py`
- 前端纯函数：`apps/platform-web/src/visual/visualDocument.js`
- Zustand：`apps/platform-web/src/visual/visualDocumentStore.js`
- 画布：`apps/platform-web/src/visual/OfflineVisualCanvas.jsx`
- 入口：`/visual-canvas`
- 自动保存：`localStorage["vibe.visualDocument.v1"]`

拖拽性能：

- pointerdown 只创建固定定位 ghost；
- pointermove 通过 rAF 直接写 `transform`，不 setState；
- pointerup 同步解析落点，只提交一次 `moveNode`。
