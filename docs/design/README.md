1. 先读 01 了解产品范围。
2. 02 定义整体架构与演进边界。
3. 03 是接口字段的单一真源；实现与联调以它为准。
4. 04 是 M2 执行层设计；与 03 冲突时，事件 envelope 与公共路径以 03 为准，
   M2 新增的工具/澄清细节以 04 为准。
