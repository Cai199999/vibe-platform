# 2026-11-04 · M1 沙盒模块阶段性总结

## 目标

为 Python AI Core 补齐 Docker 沙盒生命周期能力，为后续 Agent 提供可运行、
可验证、可销毁的前端运行环境。

## 已完成

- `SandboxProvider` 抽象：上层编排不感知底层是本地 Docker / 远程节点 / gVisor。
- `LocalDockerSandbox`：通过挂载的 `/var/run/docker.sock` 管理沙盒容器。
- 内部 API：
  - `POST /api/v1/internal/sandbox/create`
  - `POST /api/v1/internal/sandbox/apply-patch`
  - `GET  /api/v1/internal/sandbox/verify`
  - `DELETE /api/v1/internal/sandbox/{sandbox_id}`
- 沙盒镜像 `vibe-platform/sandbox-react:dev`：Node 20 + Vite 5 + React 18，
  首次使用自动构建。
- E2E：创建 → 端口映射 → 语法错误构建失败 → unified diff 修复 → 构建成功 →
  Vite 返回最新模块 → 销毁 → 404，全部通过。

## 关键设计决策

1. **端口映射**：容器内固定 5173，宿主随机端口只绑定 `127.0.0.1`；
   通过 `VITE_HMR_CLIENT_PORT` 告知 Vite HMR 客户端宿主端口，否则 HMR 会
   错误地连接 5173。
2. **文件写入**：Docker `put_archive` + 内存 tar，路径做绝对路径 / `..` 校验；
   全量文件与 unified diff（容器内 `git apply`）均支持。
3. **验证**：`timeout N npm run build|test`，返回 exit code、耗时、尾部日志，
   日志超限截断，避免超大响应。
4. **隔离**：`cap_drop=ALL`、`no-new-privileges`、内存 / CPU / PID 限额、
   非特权用户；沙盒容器带标签，python-ai 重启后可按标签恢复。
5. **构建加速**：npm 使用 `registry.npmmirror.com`；`COPY package*.json` →
   `npm install` → `COPY . .`，源码变更命中依赖缓存。
6. **失败降级**：Docker 不可用时服务仍启动，健康检查返回 `docker: UNAVAILABLE`，
   沙盒接口返回 503，不把整个 AI Core 判为不可用。

## 实测数据

- 沙盒镜像自动构建：约 28s（首次含镜像拉取）。
- 沙盒创建就绪：约 1~3s（镜像已存在）。
- 镜像大小：约 492MB（Node 基础镜像占主要部分）。
- 错误构建耗时：约 0.6~2s；成功构建：约 2s。
